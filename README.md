설문과 자료에서 사용자 문제를 찾고, 요구사항과 화면 명세로 팀의 실행 기준을 정리합니다.

## How I Work

- **사용자 조사 → 우선순위:** 흥미와 사용 의향을 따로 묻고, 참여를 망설이는 이유를 팀의 MVP 범위 논의에 반영했습니다.
- **요구사항 → 협업 기준:** 화면의 목적과 이동 조건, 예외를 문서로 정리하고 구현 상태에 맞춰 갱신했습니다.
- **화면 → 데이터 흐름:** 사용자의 선택이 저장되고 다음 화면에 반영되는 과정을 직접 구현했습니다.
- **결과 → 다음 확인 항목:** 구현된 범위와 추가 확인이 필요한 항목을 구분해 기록했습니다.
